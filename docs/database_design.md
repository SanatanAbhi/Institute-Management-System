# Institute Mangement System(IMS) --> Database Design

## Project Overview

# This project is an Institute Management System developed using:

- Backend: Django + Django REST Framework
- Frontend: Bootstrap + React.js
- Database: MySQL

The system will support three types of users:

1. Super Admin
2. Center / Franchise
3. Student
